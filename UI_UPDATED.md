## 🎨 Design Details:

### Color Palette:
```
Primary:    #6366f1 (Indigo)
Secondary:  #ec4899 (Pink)
Success:    #10b981 (Green)
Warning:    #f59e0b (Amber)
Danger:     #ef4444 (Red)

Background: Dark gradient (#0f172a → #1e1b4b)
Text:       White (#f1f5f9) / Gray (#cbd5e1)
```

### Typography:
```
Font:       Inter (clean, modern sans-serif)
Headers:    800-900 weight, gradient text
Body:       400-600 weight
Labels:     700 weight, uppercase, letter-spacing
```

### Effects:
```
Shadows:    Layered depth (sm/md/lg/xl)
Glow:       Colored shadows on primary elements
Radius:     Smooth corners (0.5rem - 1.5rem)
Blur:       Glassmorphism (8-12px backdrop blur)
```

### Animations:
```
slideDown:    Header entrance
fadeInUp:     Content reveal
fadeInLeft:   Brand animation
fadeInRight:  Status animation
scaleIn:      Badge/card entrance
pulse:        Active elements
bounce:       Upload icons
spin:         Loading spinners
blink:        Status indicators
shakeX:       Error feedback
```

## 🎯 Interactive Elements:

### Cards:
- Hover: translateY(-5px) + glow
- Active: scale animation
- Focus: border highlight

### Buttons:
- Hover: lift effect + glow
- Active: press down
- Disabled: opacity reduction
- Ripple effect on click

### Upload Areas:
- Hover: border glow + background
- Drag over: scale + intense glow
- Drop: fade in uploaded image

### Processing Steps:
- Inactive: 50% opacity
- Active: full opacity + slide + pulse
- Completed: green tint + checkmark

## 🔧 Customization:

All colors/spacing defined in CSS variables at `:root`

Want to change theme? Edit these:
```css
--primary: #6366f1;      /* Main color */
--secondary: #ec4899;    /* Accent color */
--bg-primary: #0f172a;   /* Background */
```
